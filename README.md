# 🕳️ Pothole Detection System

Sistem terintegrasi untuk deteksi dan pengukuran pothole menggunakan YOLOv8 + DepthAnything V2 + BoT-SORT + Kalman Filter.

## 🚀 Features

- ✅ YOLOv8 Detection
- ✅ DepthAnything V2 Depth Estimation
- ✅ Scale Recovery (Relative → Absolute)
- ✅ Measurement Calculation (Diameter & Depth)
- ✅ BoT-SORT Tracking
- ✅ Kalman Filter (CDKF) untuk Temporal Filtering

## 📦 Installation
